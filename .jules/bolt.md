## 2024-05-19 - Fast DOM Traversal using Element.prototype.closest
**Learning:** `closestParent()` in `reveal.js` iterates parents to find the nearest element matching a selector. The implementation dynamically checks for `matches()` on each iteration `parent.matches || parent.matchesSelector ...` which introduces small performance hits. Modern browsers support `Element.closest()` which uses optimized native traversal. We can check for `.closest()` and fallback to `.matches()` while verifying `.nodeType === 1` to skip `DocumentFragment`/`document` errors.
**Action:** Always prefer native DOM APIs like `Element.prototype.closest` and `Element.prototype.matches` when doing upward/downward DOM traversal. Cache the fallback properties outside the loop and always check `nodeType === 1` before invoking DOM methods on nodes that might reach `document` (which lacks `matches`).
