## 2024-05-09 - [DOM Traversal Optimization and Node Type Safety]
**Learning:** In legacy codebases or polyfilled environments (like PhantomJS or JSDOM used in tests), traversing the DOM up to `document` or `DocumentFragment` nodes can cause `TypeError: 'matches' called on an object that is not a valid instance of Element` if `matchesMethod` is invoked directly on those nodes without a type check. Caching the `matchesMethod` at the module scope prevents feature-detection overhead in tight loops, but doing so requires guarding against non-browser environments with a `typeof Element !== 'undefined'` check.
**Action:** When optimizing DOM traversal (e.g., in a `while (parent)` loop), always verify that the node is an Element (`nodeType === 1`) before invoking DOM-specific methods like `.matches()`, and wrap module-level browser APIs in existence checks.
