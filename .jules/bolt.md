## $(date +%Y-%m-%d) - DOM nodeName Regex optimization
**Learning:** Using regular expressions to test or match DOM element `.nodeName` properties (e.g., `/(img|video)/gi.test(element.nodeName)` or `element.nodeName.match(/section/gi)`) is significantly slower than strict equality checks (e.g., `element.nodeName === 'IMG'`). In the HTML DOM, `.nodeName` is predictably uppercase, making direct string comparison safe and highly performant. Furthermore, regex tests can accidentally match substrings (like `<custom-img>`), which `===` prevents.
**Action:** Always prefer `===` over `.test()` or `.match()` for checking HTML element tags (`nodeName` / `tagName`), especially in critical paths like layout loops and event handlers.
