## 2024-10-11 - Caching DOM Methods and Safe Traversal
**Learning:** When optimizing DOM traversal (like `closest` implementations), caching method lookups like `Element.prototype.matches` at the module level avoids repetitive feature detection overhead. However, this must be wrapped in a `typeof Element !== 'undefined'` check to prevent ReferenceErrors in SSR/non-browser contexts. Additionally, when traversing up the DOM tree, always verify nodes are Element nodes (`nodeType === 1`) before calling DOM-specific methods, as traversing up to `document` or `DocumentFragment` will result in a TypeError.
**Action:** When implementing or optimizing DOM utility functions, hoist method lookups with safety checks, and always validate node types before invoking prototype methods on them during traversal.
