## 2024-10-28 - [DOM Traversal Optimizations in Legacy Reveal.js]
**Learning:** [When optimizing DOM traversal, specifically using methods like `Element.prototype.matches`, applying it repeatedly in loops without checking for `nodeType === 1` will throw TypeErrors in legacy codebases when evaluating `document` or `DocumentFragment` nodeTypes since they do not inherit from Element. Also, caching `matches` at the module level can significantly reduce overhead during deep traversal but it requires checking for `typeof Element !== 'undefined'` to avoid ReferenceErrors during non-browser/SSR execution environments.]
**Action:** [Always verify that nodes are Element nodes (`nodeType === 1`) before invoking DOM-specific methods like `.matches()` when traversing upwards. Additionally, always check for `typeof Element !== 'undefined'` when caching Element prototype methods at the module scope.]
