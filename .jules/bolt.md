## 2024-05-18 - Optimized slide past count iteration\n**Learning:** In highly called functions that traverse slides (like getProgress/getSlidePastCount which run during transition updates), nested DOM queries `querySelectorAll` combined with implicit array allocations `toArray()` are very expensive. Flattened DOM queries with straight NodeList iteration avoids O(n) array allocations and excessive DOM layout checks.\n**Action:** Use direct NodeList enumeration `querySelectorAll(... + ":not(.stack)")` where `.stack` wrappers would complicate nested iterations, saving significant per-slide-change overhead.
