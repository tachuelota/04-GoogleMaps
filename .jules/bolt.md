## 2024-08-31 - Batching DOM Reads and Writes to avoid Layout Thrashing in `reveal.js`
**Learning:** During presentation layout, `reveal.js` resizes elements with the `.stretch` class using `layoutSlideContents()`. Previously, it iterated over each `.stretch` element and interleaved DOM writes (setting `element.style.height = '0px'`) with DOM reads (`element.parentNode.offsetHeight`), causing layout thrashing for every element. This can significantly impact performance when there are many elements.
**Action:** Always separate DOM reads and writes into distinct batches. In this case, map over the elements to zero their heights, calculate and read all parent heights in a second loop, and then restore and apply the newly calculated sizes in a final loop. This allows the browser to perform layout calculations much more efficiently.
