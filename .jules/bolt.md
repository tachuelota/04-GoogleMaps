## 2024-05-24 - Optimizing DOM Traversal and Module-Level Caching
**Learning:** When caching DOM objects or methods at the module level (e.g., `Element.prototype.matches`), always wrap it in an existence check like `typeof Element !== 'undefined'` to prevent `ReferenceError`s in non-browser/SSR environments. Also, when optimizing DOM traversal up the tree, always verify that nodes are Element nodes (`nodeType === 1`) before invoking DOM-specific methods like `.matches()`, as traversing up to `document` or `DocumentFragment` will throw a `TypeError`.
**Action:** When refactoring DOM methods to use module-level caching, always consider SSR compatibility and include a check for the global object. During DOM traversal loops, always explicitly filter for `nodeType === 1` if invoking element-specific properties or methods.
