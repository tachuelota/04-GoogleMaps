## 2024-10-29 - Optimize closestParent
**Learning:** The `closestParent` function in `js/reveal.js` retrieves `matchesMethod` on every iteration of its while loop up the DOM tree (`parent.matches || parent.matchesSelector || parent.msMatchesSelector`). Since it's called frequently during transitions and media starting, caching this method lookup globally would save operations. Furthermore, we must check `nodeType === 1` to ensure we're not calling `matches` on `document` or `DocumentFragment`, which causes `TypeError: parent.matches is not a function`.
**Action:** Extract `matchesMethod` caching to module scope, checking for `typeof Element !== 'undefined'` and caching the method if it exists. Inside `closestParent`, use the cached method but check `parent.nodeType === 1` before calling it.
